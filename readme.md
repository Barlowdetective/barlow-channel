# 📺 Barlow Channel

A live news PWA (Progressive Web App) with real-time web search powered by Claude AI.

## Features
- 🌍 International News
- 💹 Finance & Markets
- 🏀 NBA Sports
- 🎬 Entertainment (Books, Movies, Series)
- 🔊 Audio News (Text-to-Speech)
- 🎥 Video News
- 🔖 Bookmarks
- 🔍 Search
- 🌈 Dynamic vivid themes per tab
- 📲 Installable on mobile (PWA)

## Deploy on GitHub Pages

1. Upload all files to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **main branch / root folder**
4. Your app will be live at `https://YOUR_USERNAME.github.io/REPO_NAME`

## Files
- `index.html` — Main app
- `manifest.json` — PWA manifest
- `sw.js` — Service worker (offline support)
- `icon-192.svg` — App icon (192px)
- `icon-512.svg` — App icon (512px)
